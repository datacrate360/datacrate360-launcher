DataCrate360 Launcher portable mode

While this file sits next to datacrate360-launcher.exe, DataCrate360 Launcher keeps its settings, its
download cache and its record of installed apps in the DataCrate360LauncherData folder beside it, and
writes nothing to %APPDATA%. Copy the whole folder to move DataCrate360 Launcher with its settings.

Delete this file to use the normal per-user settings folder (%APPDATA%\DataCrate360 Launcher) instead.
If DataCrate360LauncherData can't be written (for example on a read-only drive), DataCrate360 Launcher says
so and uses %APPDATA%\DataCrate360 Launcher instead.
